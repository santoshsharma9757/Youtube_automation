STEP 1: GENERATE — Write Script + Prompts

  ── IMAGE MODE COMMANDS ──────────────────────────────────────────────────────

  # 1 short, image mode (DEFAULT — no extra flag needed)
  python main.py --count 1

  # 1 short, image mode, specific category
  python main.py --count 1 --category mystery_stories

  # 1 long video, image mode
  python main.py --long

  # 1 long video, image mode, specific category
  python main.py --long --category horror_stories

  # Multiple shorts, image mode
  python main.py --count 3 --category karma_stories

  ── VIDEO MODE COMMANDS ──────────────────────────────────────────────────────

  # 1 short, VIDEO mode (you will place .mp4 clip files)
  python main.py --count 1 --mode video

  # 1 short, VIDEO mode, specific category
  python main.py --count 1 --mode video --category thriller_stories

  # 1 long video, VIDEO mode
  python main.py --long --mode video

  # 1 long video, VIDEO mode, specific category
  python main.py --long --mode video --category crime_stories

  ── FORCE A SPECIFIC STORY TOPIC ─────────────────────────────────────────────

  # Force specific topic from bank (partial title match), image mode
  python main.py --topic "Woh Letter Jo 20 Saal Baad Aaya"
  python main.py --topic "Raat Ko 2 Baje Ek Message"
  python main.py --topic "Woh Ghar Jahan Ghadi Ruk Gayi"

  # Force specific topic, video mode
  python main.py --topic "48 Ghante" --mode video

  ── VOICE OPTIONS ─────────────────────────────────────────────────────────────

  # Generate script only — skip voiceover (save ElevenLabs credits)
  python main.py --count 1 --no-voice

  # Use free Edge TTS (hi-IN-MadhurNeural) instead of ElevenLabs
  python main.py --count 1 --local-tts

  ── WHAT YOU GET AFTER GENERATE ──────────────────────────────────────────────

  output/veo_prompts/{story_name}.txt
    → Full reference file (voiceover + prompts + SEO metadata)

  output/veo_prompts/{story_name}_zapi_prompts.txt        ← USE THIS IN ZAPI
    → ONLY image prompts, one per block (no voiceover, no headers, no separators)
    → Paste this directly into Zapi Flow — it will generate exactly N images
    → Each block = one scene image

  input/clips/{story_folder}/
    plan.json           ← Story structure (scenes, voiceovers, prompts)
    metadata.json       ← SEO + YouTube upload metadata
    scene_1.mp3         ← Raunak voiceover for scene 1
    scene_2.mp3         ← Raunak voiceover for scene 2
    ...                 ← (one .mp3 per scene, matches scene count)
