# Chintu Stories - AI Kids Animation Channel
# Commands Cheatsheet (Simplified - June 2026)
# Channel: YouTube Kids + Facebook Reels
# Style: 3D Pixar Animation | Moral Stories | Hindi Voiceover

================================================================================
 🎬 1. GENERATE SCENE PROMPTS
================================================================================

Choose ONE of these commands to generate a fresh story plan and prompts:

## Option A: Video/Veo Story (3 video scenes, max 18s)
python main.py --count 1 --videos

## Option B: Image Panning Story (4 image scenes, 25-35s)
python main.py --count 1 --image

Prompts file will be saved directly to:
  → output/veo_prompts/{timestamp}_{slug}.txt

A metadata folder will be created at:
  → input/clips/{timestamp}_{slug}/


================================================================================
 📥 2. PLACE GENERATED ASSETS
================================================================================

Generate your assets using external tools (Veo / Midjourney / DALL-E) based on the prompts.txt file, then copy them inside:
  → input/clips/{timestamp}_{slug}/

Files to copy:
- For Video stories: Place 1.mp4, 2.mp4, 3.mp4
- For Image stories: Place 1_image.png, 2_image.png, 3_image.png, 4_image.png


================================================================================
 ⚡ 3. STITCH & COMPILE / UPLOAD
================================================================================

## Step A: Compile locally (Keep final video in output/final_videos/)
python main.py --stitch

## Step B: Upload & Clear (CLEANS UP everything local after upload!)
python main.py --upload

NOTE: With the --upload command:
1. Video uploads immediately to YouTube + Facebook.
2. The local compiled .mp4 video and the input clips folder are automatically DELETED to keep your drive clean.
